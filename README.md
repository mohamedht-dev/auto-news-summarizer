# Tech News Headline Fetcher (جالب عناوين الأخبار التقنية)

## نظرة عامة

هذا المشروع عبارة عن أداة سطر أوامر خفيفة الوزن (CLI) مبنية بلغة بايثون، تقوم بجلب وعرض عناوين الأخبار التقنية من مصادر محددة. يهدف المشروع إلى توفير طريقة سريعة للمستخدمين لمتابعة آخر المستجدات في عالم التكنولوجيا.

## الميزات

- **جلب العناوين:** يقوم بجلب العناوين الرئيسية لأخبار التكنولوجيا من مواقع إخبارية تقنية.
- **عرض بسيط:** يعرض العناوين بطريقة واضحة ومباشرة.
- **سهولة الاستخدام:** واجهة سطر أوامر بسيطة وسهلة التشغيل.

## المتطلبات

- Python 3.x
- `requests` مكتبة لطلب صفحات الويب.
- `BeautifulSoup4` مكتبة لتحليل HTML.

## التثبيت

1.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/mohamedht-dev/auto-news-summarizer.git
    cd auto-news-summarizer
    ```

2.  **إنشاء بيئة افتراضية (موصى به):**
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # لنظامي Linux/macOS
    # venv\Scripts\activate  # لنظام Windows
    ```

3.  **تثبيت التبعيات:**
    ```bash
    pip install -r requirements.txt
    ```

## الاستخدام

لتشغيل جالب العناوين، ببساطة قم بتنفيذ السكريبت:

```bash
python main.py
```

سيقوم البرنامج بجلب أحدث 5 عناوين أخبار تقنية وعرضها.

## الخطط المستقبلية (Roadmap)

نخطط لتطوير هذا المشروع ليصبح أداة أكثر قوة وذكاءً، تتضمن الميزات التالية:

-   **تلخيص حقيقي بالذكاء الاصطناعي:** استخدام نماذج لغوية كبيرة (LLMs) لتلخيص محتوى المقالات بدلاً من العناوين فقط.
-   **دعم مصادر متعددة:** جلب الأخبار من خلاصات RSS متنوعة لضمان المرونة وتجنب الاعتماد على كشط HTML.
-   **إزالة التكرار والتصنيف:** التعرف على الأخبار المكررة وتصنيفها حسب الموضوع (مثل AI، الأمن السيبراني، البرمجة).
-   **تصدير الملخصات:** إمكانية تصدير الملخصات بصيغ مختلفة (Markdown, JSON, HTML).
-   **أتمتة GitHub Actions:** لتشغيل المشروع بشكل دوري وتحديث الملخصات تلقائياً.
-   **إضافة اختبارات:** لضمان جودة الكود واستقراره.
