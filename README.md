# AI-Powered Tech News Summarizer (ملخص أخبار تقنية يعمل بالذكاء الاصطناعي)

## نظرة عامة

هذا المشروع عبارة عن أداة بسيطة مبنية بلغة بايثون تقوم بجلب آخر الأخبار التقنية من مصادر محددة (مثل TechCrunch) وتقدم ملخصًا موجزًا للعناوين الرئيسية. يهدف المشروع إلى توفير طريقة سريعة للمستخدمين لمتابعة أهم التطورات في عالم التكنولوجيا دون الحاجة لقراءة المقالات كاملة.

## الميزات

- **جلب الأخبار:** يقوم بجلب العناوين الرئيسية لأخبار التكنولوجيا من مواقع إخبارية تقنية.
- **تلخيص بسيط:** يقدم ملخصًا موجزًا لكل عنوان خبر (ملخص مبدئي، يمكن تطويره لاحقًا باستخدام نماذج AI متقدمة).
- **سهولة الاستخدام:** واجهة سطر أوامر بسيطة وسهلة التشغيل.

## المتطلبات

- Python 3.x
- `requests` مكتبة لطلب صفحات الويب.
- `BeautifulSoup4` مكتبة لتحليل HTML.

## التثبيت

1.  **استنساخ المستودع:**
    ```bash
    git clone https://github.com/YOUR_USERNAME/auto-news-summarizer.git
    cd auto-news-summarizer
    ```

2.  **إنشاء بيئة افتراضية (موصى به):**
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # لنظامي Linux/macOS
    # venv\Scripts\activate  # لنظام Windows
    ```

3.  **تثبيت التبعيات:**
    ```bash
    pip install -r requirements.txt
    ```

## الاستخدام

لتشغيل الملخص، ببساطة قم بتنفيذ السكريبت:

```bash
python main.py
```

سيقوم البرنامج بجلب أحدث 5 عناوين أخبار تقنية وعرض ملخص لكل منها.
